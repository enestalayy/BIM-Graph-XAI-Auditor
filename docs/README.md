# Tez Dokümantasyonu

Bu klasör, tez metninin yazımında kullanılacak yöntem ve bulguların canlı
deposudur. Her dosya bir tez bölümüne karşılık gelir ve kodla birlikte
güncellenir. Yazım kuralları proje kökündeki `CLAUDE.md` dosyasındadır.

| Dosya | İçerik |
|---|---|
| `01_introduction.md` | Problem, literatür, neuro-symbolic yaklaşım |
| `02_methodology_etl_kg.md` | IFC ayrıştırma, birimler, AABB, bilgi grafiği şeması |
| `03_methodology_spatial_audit.md` | Kesişim tespiti, kural dili ve Cypher derleme |
| `04_methodology_xai_rag.md` | Kanıt paketi, açıklama üretimi, dayanaklandırma (grounding) doğrulaması |
| `05_validation_results.md` | Doğrulama tasarımı, metrikler ve sonuçlar |
