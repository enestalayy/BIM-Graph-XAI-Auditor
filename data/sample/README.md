# Sample IFC models

| File | Discipline | Schema | Length unit |
|---|---|---|---|
| `Building-Architecture.ifc` | Architecture | IFC4X3_ADD2 | millimetre |
| `Building-Hvac.ifc` | HVAC (MEP) | IFC4X3_ADD2 | millimetre |

Both files describe the same small building ("ifc silly sample scene") and share
site, building and storey GlobalIds as well as the local coordinate system, so they
can be federated without any transformation.
